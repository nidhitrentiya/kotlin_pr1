## 🚀 Getting Started

### Prerequisites

- Kotlin compiler or Android Studio / IntelliJ IDEA.
- JDK installed if required by the project.
- Git installed to clone the repository.

### Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/nidhitrentiya/kotlin_pr1.git
```

**2. Open the project**

Open the cloned project in your preferred Kotlin development environment.

**3. Run the program**

If the project contains a standalone Kotlin file, compile and execute it using:

```bash
kotlinc Main.kt -include-runtime -d main.jar
java -jar main.jar
```

Make sure the filename and entry point match your actual source code. If it is a Gradle project, open it in the IDE and run the appropriate Kotlin main function.
